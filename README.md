# Flora AI Chatbot

Flora is a beginner-friendly chatbot built using Python and Streamlit. It provides a simple chat interface, responds to common messages using predefined keywords, and maintains conversation history.

## Features
- Interactive chat interface
- Keyword-based responses
- Conversation history
- Clear Chat button
- About Flora sidebar

## Technologies Used
- Python
- Streamlit

## How to Run
1. Install Python.
2. Install the required library:
   `pip install -r requirements.txt`
3. Run the application:
   `python -m streamlit run app.py`

## Current Limitation
The chatbot currently uses predefined responses. It is not yet connected to a real AI model.
